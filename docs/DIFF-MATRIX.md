## 差异化矩阵（场景 → 功能 → 怎么验）

| # | 场景（患者侧） | 功能 | 怎么验 | 家族对照（为何独有） |
| --- | --- | --- | --- | --- |
| D1 | 拿到病理报告，「胸腺瘤/胸腺癌」一词之差，需要复核 | 病理与复核页：原报告逐字原文+复核报告并存，逐字段回溯原文，系统不判定病理类型 | A/B 档案各有一条原报告+一条复核报告，并列显示互不覆盖；grep 全站无"您是/诊断为"判定句 | breast/cervical 的病理记录都是"一张报告一条"，无双报告并列语义 |
| D2 | CACA 推荐 TNM 9版、NCCN 沿用 Masaoka-Koga，两位医生说法不同 | 分期档案：双体系并列记录（体系名+版本+医生原文+日期），不换算不推荐 | 录入两体系后 UI 并列显示；全站无"换算"按钮；检查器断言 stage 视图同时渲染两体系块 | cervical 只有 FIGO 单体系档案 |
| D3 | MG 合并症与肿瘤症状混在一起；免疫治疗期间怕诱发肌无力 | 肌无力与免疫页：MG 状态三态（未记录/疑似/确诊）+ 表达面症状条 + 免疫治疗标记卡，两列并置不写因果 | MG 未记录给空态+下一步；免疫治疗卡固定带 irAE 提示【待核】占位；grep 无"危象判定" | 家族无任何 MG/副肿瘤线（aml 的感染线是化疗粒缺语境，语义不同） |
| D4 | 无肿瘤标志物可依赖，随访全靠 CT，年年等结果（scanxiety） | 影像随访页：影像报告留存 + 距上次/距下次天数 + 辐射次数计数（不评判） | "距下次"只由医嘱间隔推导（无医嘱显示"未约定"）；全站无标准间隔数字；下次日期计算有单测 | breast 影像（钼靶/超声）只是指标来源之一，无独立随访节奏页 |
| D5 | 前纵隔肿物鉴别期（生殖细胞瘤/淋巴瘤）等待焦虑 | 症状与感受页 + 鉴别检查清单（AFP/β-hCG 标注"鉴别参考，非活动指标"） | AFP 卡片文案含"鉴别"字样；症状表达面与指标面并置 | 家族仓的标志物卡均为"疾病活动"语义，本仓语义反转向 |
| D6 | 多科就诊（胸外/放疗/神内）资料反复解释 | 复诊准备：资料包清单+带来源摘要导出+问题候选 | 导出文件与页面数据一致；每条带来源；私密三出口过滤 | 家族通用能力，但资料包分组按"病理/分期/影像/MG"四类（D1-D3 的复用） |

## 从家族抄什么（结构，Q2 落实）

- 首页 hero + 状态卡 + 快捷入口三件（cervical vDashboard 结构）。
- 病情整理五 Tab（资料库/整理草稿核对/病情档案/指标检测/病情汇总）——逐字保留家族词表。
- 指标卡 3D 翻转（breast aria-pressed 模式）+ 一图秀 svg.chart 980×420（cervical 层序）。
- 治疗线折叠卡：32 号模板 details 单元（一次住院/一个疗程一个单元）。
- 疾病概要：starter assets/patterns/disease-primer.js（逐字节复用）+ 原创四段数据。
- 整页视图两入口、AI 面板右侧 25–45%、顶栏三段式：家族通用件。

## 暂缓项（孤儿预防清单）

- 性与生育、营养支持：不排入首版（S8 裁剪记录）；导航中不出现，避免空壳页。
- 儿童胸腺癌、胸腺瘤独立档案：明确超范围。
