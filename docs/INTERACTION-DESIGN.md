# INTERACTION-DESIGN · 交互路径（IP1，28 号）

状态：M1 定稿 v0.2 原型口径；每条路径有可观察产物+回首页步。孤儿页约束：12 一级页全部被至少一条路径经过（IP2/X1 走查在 M2 执行并出计数）。

## P-01 新患者首日（F1）

入口：看板「建立病理档案」→ 步骤：整页视图录入原报告原文→保存版本 → 产物：病理档案 1 条+看板最近变化+1 → 回：Esc/返回按钮。

## P-02 病理复核（F2）

入口：病理与复核「⋯ 更多」→「录入复核意见」→ 产物：复核条目（双报告并列）→ 回。

## P-03 双分期录入（F3）

入口：分期档案 → 体系块「录入医生原文」×2 → 产物：两体系并列条目 → 回。

## P-04 治疗事件（F4）

入口：治疗历程「新增事件」→ 产物：折叠卡+1（免疫事件带提示标记）→ 回。

## P-05 复查到点（F5）

入口：看板 alert-strip → 影像随访 → 录报告 → 产物：影像条目+节奏重算 → 回。

## P-06 化验录入（F6）

入口：检查与指标 → 录数值 → 产物：指标卡+1（翻面看趋势）→ 回。

## P-07 复诊导出（F7）

入口：复诊准备 → 勾资料→导出 → 产物：.md 文件下载 → 回。

## P-08 MG 表达面（F8）

入口：肌无力与免疫 → 三态选择+症状条 → 产物：并置视图更新 → 回。

## P-09 疾病概要（F9）

入口：顶栏「?」/看板 primer 文字按钮 → 整页面板四段 → 产物：无写入，深链 #disease-primer → 回：Esc/back 关闭焦点还原。

## P-10 一图秀查看（补充路径）

入口：看板快捷或导航「病情一图秀」→ 切指标/时间窗/治疗条开关 → 产物：视图联动 → 回。

## P-11 AI 候选（补充路径）

入口：任意页「和 AI 讨论」（预填，不自动发）→ 独立打开进演示面板（明说未接通）→ 产物：草稿文案进输入框 → 回。

## P-12 临床研究线索（F10）

入口：临床研究 → 建条件→检索→候选 → 产物：候选线索+1（证据链可见）→ 回。
