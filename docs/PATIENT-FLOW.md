# PATIENT-FLOW · 患者流程（M1）

每条流程 = 触发→动作→产物→回首页。对应 SCENARIOS S1–S8；每条挂 B 级方向或 D 级假设标签（0 访谈声明见 USER-RESEARCH）。

## F1 新患者上手（首次打开）

1. 打开工作台 → 看板 hero 显示档案名与"这次想先看什么"。
2. 点「建立病理档案」task-entry → 整页视图（病理与复核）。
3. 录入原报告逐字原文 → 保存为新版本 → 产物：病理档案首条。
4. 返回：Esc 或返回按钮 → 主页滚动位置与焦点保持。
（D 级假设）

## F2 病理复核对照（S1）

1. 病理与复核页 → 「⋯ 更多」→「录入复核意见」。
2. 填机构/日期/复核结论原文 → 保存。
3. 产物：双报告并列视图（原报告不变，复核标记"第二意见"）。
4. 回首页。（B2）

## F3 分期录入（S2）

1. 分期档案页 → 两体系块各一个「录入医生原文」。
2. 录 Masaoka-Koga 条目 → 录 TNM 条目（体系+版本必填）。
3. 产物：并列视图，逐条带医生原文。
4. 回首页。（B6/D2）

## F4 治疗事件（S3）

1. 治疗历程页 → 新增事件（手术/化疗/放疗/免疫）。
2. 填类型/开始日/方案名（候选词汇表可选也可自填）/科室。
3. 产物：折叠卡单元追加；免疫事件自动带 irAE 提示标记。
4. 回首页。（B 级方向）

## F5 复查到点（S5）

1. 看板 alert-strip 显示「距上次胸部 CT N 天」→ 点进影像随访。
2. 录新 CT 报告 → 距上次/距下次重算。
3. 产物：影像条目+报告留存。
4. 回首页。（B3）

## F6 化验录入与趋势（S6）

1. 检查与指标页 → 按类别录指标（血常规/生化/免疫相关）。
2. 产物：指标卡正面（值/单位/日期/来源/次数），点卡翻面看趋势。
3. AFP/β-hCG 卡带"鉴别参考"标注。
4. 回首页。（B 级方向）

## F7 复诊准备（S7）

1. 复诊准备页 → 勾选资料 → 生成问题候选（AI 入口预填，不自动发）。
2. 导出摘要 → 得到真实 .md 文件，内容与页面一致。
3. 回首页。（B6）

## F8 MG 状态与表达面（S4）

1. 肌无力与免疫页 → MG 三态选择（首次进入空态给"问医生"指引）。
2. 记录症状表达面条目（眼睑下垂/无力/气短等，患者语言）。
3. 产物：表达面与治疗面并置视图。
4. 回首页。（B4/B5）

## F9 疾病概要（? 按钮）

1. 顶栏「?」或看板文字按钮 → 整页面板四段（定义→医学资料规范和指南情况→治疗全景→发展趋势）。
2. history pushState 深链 #disease-primer，Esc/back 退一层。
3. 产物：阅读理解，无写入。
4. 关闭后焦点回触发按钮。（P1–P9）

## F10 临床研究线索（35 号链路）

1. 临床研究页 → 建档条件（诊断=胸腺癌、既往治疗、地点）→ 双通道检索候选 → 分层+证据链查看 → 存候选线索。
2. 无匹配指数列、无判读列。
3. 回首页。（35 号）
