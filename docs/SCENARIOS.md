# SCENARIOS · 场景清单（M1，D 级假设标签制）

主体：胸腺癌患者与家属（胸腺瘤不纳入首版，但病理名称教育中需解释两者区别）。病程覆盖：确诊等待期→围手术期→术后辅助/放化疗→常规随访→复发/晚期。
全部场景为 0 访谈下的产品假设（P0 标签），用户原话=无，只有 B 级转述方向。

## S1 病理确认与复核（B1/B2 方向）

- 触发：拿到病理报告，或考虑/完成病理复核。
- 动作：录入原报告逐字原文+机构+日期；录入复核报告；两份并列不覆盖。
- 产物：病理档案（原/复核并列、逐字段可回溯原文）。
- 验收：A/B 档案切换后原报告与复核报告并存；任何字段点开能看到报告原文片段；系统不出现"您是胸腺癌"类判定句。

## S2 双分期体系对照（B6 方向）

- 触发：不同医院/国内外医生给出 Masaoka-Koga 或 TNM（8/9版）不同表述。
- 动作：分别录医生原文+体系+版本+日期；查看并列视图。
- 产物：分期档案（双体系、不换算、医生原文并列）。
- 验收：录入两条不同体系记录后互不覆盖；界面无"换算"按钮；每条都显示体系名+版本+原文。

## S3 治疗历程回顾（B 级方向，医生任务红线自查：按"我经历了什么"组织，不按"方案选择"组织）

- 触发：手术/化疗/放疗/免疫治疗任一事件后。
- 动作：按医生原文记录事件（类型、开始日、方案名、科室）。
- 产物：治疗时间线（折叠卡：一次住院/一个疗程为一个单元）。
- 验收：时间线按日期排序、事件可点开看来源；无"线序"自动编号（只有医生写了才显示医生写的称谓）。

## S4 肌无力与免疫（B4/B5 方向）

- 触发：MG 状态变化；免疫治疗期间新发症状。
- 动作：记录 MG 状态（三态）+症状表达面条目；免疫治疗卡固定标记。
- 产物：肌无力与免疫页（表达面与治疗面并置，不写因果）。
- 验收：MG 未记录时页面给空态+下一步（问医生）；免疫治疗期间的症状录入提示【待核】求助占位。

## S5 影像随访（B3 方向）

- 触发：按医嘱时间到点或拿到新 CT 报告。
- 动作：录影像报告（部位、机构、结论原文）；看"距上次/距下次"。
- 产物：影像随访页（节奏视图+报告留存）。
- 验收：不写标准间隔数字；只有医嘱写了间隔才显示间隔；辐射累计只计数不评判。

## S6 化验与指标（B 级方向）

- 触发：拿到化验单。
- 动作：录入数值+单位+方法+机构；分类查看与趋势。
- 产物：指标卡+一图秀曲线（可比分组）。
- 验收：AFP/β-hCG 卡片标注"用于鉴别诊断参考，非胸腺癌活动指标"；方法/单位变化拆可比组；无好坏箭头。

## S7 复诊准备（B6 方向）

- 触发：复诊前。
- 动作：勾选要带资料+生成问题清单。
- 产物：带来源的摘要导出（真实文件）。
- 验收：导出文件内容与页面数据一致；私密项默认排除且显示"N 条中私密 M 条"。

## S8 心理与家庭（B1 方向）

- 触发：等待结果、复发恐惧等情绪负荷时。
- 动作：记录心情与想对医生说的话（候选问题）。
- 产物：心理支持页（表达面+问题候选）。
- 验收：AI 生成内容全部标"候选"，不自动发送。

## 裁剪记录

- 性与生育/营养支持：胸腺癌人群特征（中老年、非生殖细胞）下证据更弱，M1 裁剪为"未排入首版"，记暂缓项。
- 临床试验线：按 35 号四段链路做"候选线索"层（建档、双通道检索、分层+证据链、候选线索），无匹配指数与判读列。
